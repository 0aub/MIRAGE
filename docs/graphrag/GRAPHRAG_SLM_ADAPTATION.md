# GraphRAG Implementation with SLMs (Allam)

**Date:** January 2025
**Model:** Allam (Arabic SLM)
**Challenge:** Implement GraphRAG with smaller language models

---

## Overview

This document adapts the GraphRAG implementation plan for use with Small Language Models (SLMs), specifically Allam for Arabic language processing.

**Key Principle:** Reduce LLM dependency using rule-based and NLP approaches where possible, reserving SLM calls for tasks that truly need language understanding.

---

## Architecture: Both Databases Required

### ✅ We MUST use both Neo4j AND Qdrant

**Why:**
- **Vector DB (Qdrant)**: Semantic search on text chunks (essential)
- **Graph DB (Neo4j)**: Entities, relationships, communities (essential)
- **Together**: 0.96 answer relevancy vs 0.89 (graph only) or 0.91 (vector only)

**Storage breakdown:**

```
Qdrant (Vector DB):
├── Text chunk embeddings
├── Chunk metadata
└── Fast semantic similarity search

Neo4j (Graph DB):
├── Entity nodes
├── Relationship edges
├── Community nodes (Leiden algorithm)
├── Community summaries (generated by Allam)
└── Hierarchical structure
```

**Both databases are core to GraphRAG - removing either cripples the system.**

---

## SLM Adaptation Strategy

### Approach: Hybrid Rule-Based + SLM

Instead of using LLMs for everything, we'll use:

1. **Rule-based & NLP libraries** - Where possible (fast, cheap, reliable)
2. **Allam SLM** - Only where language understanding is essential
3. **Optimized prompts** - Shorter, more focused for smaller models
4. **Caching** - Aggressive caching to reduce calls

### Comparison: Standard vs SLM-Adapted

| Component | Standard GraphRAG | SLM-Adapted (Allam) |
|-----------|-------------------|---------------------|
| Entity Extraction | LLM-based | **spaCy/CAMeL + Allam** |
| Relationship Extraction | LLM inference | **Co-occurrence + Allam validation** |
| Entity Normalization | LLM-based | **Rule-based heuristics** |
| Community Summaries | LLM generation | **Allam with optimized prompts** |
| Query Answering | LLM generation | **Allam with focused context** |
| Evaluation | LLM scoring | **Rule-based metrics + Allam** |

```python
class EntityNormalizer:
    """
    Rule-based entity normalization (no LLM required).
    Optimized for Arabic with Allam as fallback.
    """

    def __init__(self, allam_client=None):
        self.allam_client = allam_client
        self.cache = {}

        # Arabic-specific title patterns
        self.arabic_titles = [
            r'\b(الدكتور|الأستاذ|المهندس|الشيخ)\s+',
            r'\b(د|أ|م)\.\s*',
        ]

    def normalize_entity_name(self, name: str, entity_type: str) -> str:
        """Normalize using rules first, Allam as fallback."""

        # Step 1: Basic normalization (no LLM)
        normalized = self._rule_based_normalization(name, entity_type)

        # Step 2: Check cache
        if normalized in self.cache:
            return self.cache[normalized]

        # Step 3: Only use Allam for ambiguous cases (rare)
        if self._is_ambiguous(normalized) and self.allam_client:
            normalized = self._allam_normalization(normalized, entity_type)

        self.cache[normalized] = normalized
        return normalized

    def _rule_based_normalization(self, name: str, entity_type: str) -> str:
        """Rule-based normalization (90% of cases)."""

        # Remove extra whitespace
        name = " ".join(name.split())

        # Remove Arabic titles
        for pattern in self.arabic_titles:
            name = re.sub(pattern, '', name)

        # Remove English titles
        titles = [r'\b(Dr|Mr|Mrs|Ms|Prof)\.\s+', r'\b(PhD|MD)\s*$']
        for pattern in titles:
            name = re.sub(pattern, '', name, flags=re.IGNORECASE)

        # Handle "Last, First" format
        if ',' in name:
            parts = name.split(',')
            if len(parts) == 2:
                name = f"{parts[1].strip()} {parts[0].strip()}"

        # Normalize Arabic characters
        name = self._normalize_arabic_chars(name)

        # Capitalize properly
        name = " ".join(word.capitalize() for word in name.split())

        return name.strip()

    def _normalize_arabic_chars(self, text: str) -> str:
        """Normalize Arabic character variations."""
        # Normalize Alef variants
        text = re.sub('[إأآا]', 'ا', text)
        # Normalize Yaa variants
        text = re.sub('ى', 'ي', text)
        # Remove diacritics
        text = re.sub('[\u064B-\u065F]', '', text)
        return text

    def _is_ambiguous(self, name: str) -> bool:
        """Check if name needs LLM normalization (rare cases)."""
        # Only true for very complex cases
        # Most names handled by rules
        return False  # Conservative: avoid LLM calls

    def _allam_normalization(self, name: str, entity_type: str) -> str:
        """Fallback: Use Allam only when necessary."""
        prompt = f"""
        قم بتطبيع اسم الكيان التالي إلى شكله القياسي:
        الاسم: {name}
        النوع: {entity_type}

        أعد الاسم المُطبّع فقط (بدون عناوين أو ألقاب).
        """

        response = self.allam_client.generate(prompt, max_tokens=50)
        return response.strip()
```

**Result:** 90% of normalizations done with zero LLM calls!

#### Task 1.3: Evaluation Framework - RULE-BASED + ALLAM

**Adapt metrics to use rules + selective Allam calls:**

```python
class SLMRAGEvaluator:
    """
    Evaluation optimized for SLMs (Allam).
    Uses rule-based metrics where possible.
    """

    def __init__(self, allam_client):
        self.allam_client = allam_client

    def evaluate_answer(
        self,
        question: str,
        answer: str,
        contexts: List[str],
        ground_truth: str = None
    ) -> EvaluationMetrics:
        """Evaluate using lightweight metrics."""

        # Faithfulness: Rule-based + Allam validation
        faithfulness = self._evaluate_faithfulness_hybrid(answer, contexts)

        # Answer relevancy: Allam with focused prompt
        answer_relevancy = self._evaluate_relevancy_slm(question, answer)

        # Context metrics: Rule-based
        context_recall = self._evaluate_recall_rules(contexts, ground_truth) if ground_truth else 0.0
        context_precision = self._evaluate_precision_rules(contexts, question)

        return EvaluationMetrics(
            faithfulness=faithfulness,
            answer_relevancy=answer_relevancy,
            context_recall=context_recall,
            context_precision=context_precision
        )

    def _evaluate_faithfulness_hybrid(self, answer: str, contexts: List[str]) -> float:
        """Hybrid: Check factual grounding using rules + Allam."""

        # Step 1: Extract claims from answer (rule-based)
        claims = self._extract_claims_rules(answer)

        # Step 2: Check each claim against contexts (keyword matching)
        supported_count = 0
        for claim in claims:
            if self._claim_supported_by_contexts_rules(claim, contexts):
                supported_count += 1

        rule_score = supported_count / len(claims) if claims else 1.0

        # Step 3: Allam validation (only if rule score is ambiguous)
        if 0.3 < rule_score < 0.7:  # Ambiguous range
            allam_score = self._allam_faithfulness_check(answer, contexts)
            return (rule_score + allam_score) / 2

        return rule_score

    def _extract_claims_rules(self, answer: str) -> List[str]:
        """Extract factual claims using sentence splitting."""
        # Simple sentence splitting
        sentences = re.split(r'[.!?]+', answer)
        return [s.strip() for s in sentences if len(s.strip()) > 10]

    def _claim_supported_by_contexts_rules(self, claim: str, contexts: List[str]) -> bool:
        """Check if claim is supported using keyword matching."""
        # Extract key terms from claim
        claim_terms = set(self._extract_key_terms(claim))

        for context in contexts:
            context_terms = set(self._extract_key_terms(context))
            # If >50% of claim terms in context, consider supported
            overlap = len(claim_terms & context_terms)
            if overlap / len(claim_terms) > 0.5:
                return True

        return False

    def _extract_key_terms(self, text: str) -> List[str]:
        """Extract key terms (nouns, named entities)."""
        # Simple: Remove stop words, keep longer words
        words = text.split()
        # Filter stop words (Arabic + English)
        stop_words = {'the', 'a', 'an', 'في', 'من', 'إلى', 'على', 'هذا', 'هذه'}
        key_terms = [w for w in words if w.lower() not in stop_words and len(w) > 3]
        return key_terms

    def _allam_faithfulness_check(self, answer: str, contexts: List[str]) -> float:
        """Allam validation (used sparingly)."""
        prompt = f"""
        هل الإجابة التالية مدعومة بالسياقات المقدمة؟

        الإجابة: {answer[:500]}

        السياقات:
        {chr(10).join(contexts[:3])}

        قيّم من 0.0 (غير مدعومة) إلى 1.0 (مدعومة تماماً).
        أعد رقماً فقط.
        """

        response = self.allam_client.generate(prompt, max_tokens=10)
        try:
            return float(response.strip())
        except:
            return 0.5

    def _evaluate_relevancy_slm(self, question: str, answer: str) -> float:
        """Evaluate relevancy using Allam with focused prompt."""

        # First: Rule-based quick check
        question_terms = set(self._extract_key_terms(question))
        answer_terms = set(self._extract_key_terms(answer))
        overlap = len(question_terms & answer_terms)

        if overlap == 0:
            return 0.0  # No overlap = not relevant

        if overlap / len(question_terms) > 0.8:
            return 1.0  # High overlap = very relevant

        # Ambiguous: Use Allam
        prompt = f"""
        هل الإجابة ذات صلة بالسؤال؟

        السؤال: {question}
        الإجابة: {answer[:300]}

        قيّم من 0.0 إلى 1.0
        أعد رقماً فقط.
        """

        response = self.allam_client.generate(prompt, max_tokens=10)
        try:
            return float(response.strip())
        except:
            return 0.5

    def _evaluate_recall_rules(self, contexts: List[str], ground_truth: str) -> float:
        """Rule-based recall calculation."""
        if not ground_truth:
            return 0.0

        gt_terms = set(self._extract_key_terms(ground_truth))
        context_terms = set()
        for ctx in contexts:
            context_terms.update(self._extract_key_terms(ctx))

        overlap = len(gt_terms & context_terms)
        return overlap / len(gt_terms) if gt_terms else 0.0

    def _evaluate_precision_rules(self, contexts: List[str], question: str) -> float:
        """Rule-based precision calculation."""
        if not contexts:
            return 0.0

        question_terms = set(self._extract_key_terms(question))
        relevant_count = 0

        for context in contexts:
            context_terms = set(self._extract_key_terms(context))
            overlap = len(question_terms & context_terms)
            if overlap / len(question_terms) > 0.3:  # 30% threshold
                relevant_count += 1

        return relevant_count / len(contexts)
```

**Result:** Reduced Allam calls by 70-80% using rule-based metrics!

```python
class SLMCommunitySummarizer:
    """
    Community summarization optimized for SLMs (Allam).
    """

    def __init__(self, neo4j_client, allam_client, community_detector):
        self.neo4j_client = neo4j_client
        self.allam_client = allam_client
        self.community_detector = community_detector

    def generate_community_summary(
        self,
        community_id: str,
        level: int,
        child_summaries: Dict[str, CommunitySummary] = None
    ) -> CommunitySummary:
        """Generate summary using Allam with optimized prompts."""

        # Get entities and relationships
        entities = self.community_detector.get_community_entities(community_id, level)
        relationships = self.community_detector.get_community_relationships(community_id, level)

        # Get child summaries
        child_summary_texts = []
        if level > 0 and child_summaries:
            child_comms = self._get_child_communities(community_id, level)
            for child_id in child_comms:
                if child_id in child_summaries:
                    child_summary_texts.append(child_summaries[child_id].summary)

        # Generate summary with optimized prompt for SLM
        summary_text = self._generate_summary_slm(
            entities=entities,
            relationships=relationships,
            child_summaries=child_summary_texts,
            level=level
        )

        # Extract keywords (rule-based)
        keywords = self._extract_keywords_rules(entities, relationships)

        return CommunitySummary(
            community_id=community_id,
            level=level,
            summary=summary_text,
            entity_count=len(entities),
            relationship_count=len(relationships),
            child_summaries=child_summary_texts,
            keywords=keywords
        )

    def _generate_summary_slm(
        self,
        entities: List[Dict],
        relationships: List[Dict],
        child_summaries: List[str],
        level: int
    ) -> str:
        """
        Generate summary with SLM-optimized prompt.

        Key optimizations for small models:
        1. Shorter prompt
        2. Clear structure
        3. Limited context (top 20 entities)
        4. Focused instructions
        """

        # Limit entities to avoid context overflow
        top_entities = entities[:20]  # Top 20 most important

        # Format entities concisely
        entity_list = ", ".join([f"{e['name']} ({e['type']})" for e in top_entities])

        # Format relationships concisely
        rel_list = "\n".join([
            f"{r['source']} → {r['target']}"
            for r in relationships[:15]  # Top 15 relationships
        ])

        # Child summaries (if any)
        child_context = ""
        if child_summaries:
            child_context = f"\n\nالمجموعات الفرعية:\n" + "\n".join(
                [f"- {s[:150]}..." for s in child_summaries[:3]]  # Top 3, truncated
            )

        # Optimized prompt for Arabic SLM
        if level == 0:  # Bottom level
            prompt = f"""
            لخّص هذه المجموعة من الكيانات المترابطة.

            الكيانات: {entity_list}

            العلاقات الرئيسية:
            {rel_list}

            التعليمات:
            1. حدد الموضوع الرئيسي
            2. اذكر الكيانات الأساسية
            3. اشرح العلاقات المهمة
            4. اكتب 2-3 فقرات

            الملخص:
            """
        else:  # Higher levels
            prompt = f"""
            لخّص هذه المجموعة الشاملة.

            الموضوع: مجموعة من {len(entities)} كياناً مترابطاً
            {child_context}

            التعليمات:
            1. حدد الموضوع العام
            2. اربط بين المجموعات الفرعية
            3. اذكر الأنماط الرئيسية
            4. اكتب 2-3 فقرات

            الملخص:
            """

        # Generate with conservative token limit
        response = self.allam_client.generate(
            prompt,
            max_tokens=500,  # Conservative for SLM
            temperature=0.3  # Lower = more focused
        )

        return response.strip()

    def _extract_keywords_rules(
        self,
        entities: List[Dict],
        relationships: List[Dict]
    ) -> List[str]:
        """Extract keywords using rules (no LLM)."""

        keywords = []

        # Add entity names (top 5)
        entity_names = [e['name'] for e in entities[:5]]
        keywords.extend(entity_names)

        # Add entity types
        entity_types = list(set([e['type'] for e in entities]))
        keywords.extend(entity_types)

        # Add relationship types
        rel_types = list(set([r.get('relationship_type', '') for r in relationships]))
        keywords.extend([rt for rt in rel_types if rt])

        # Return unique, top 10
        return list(set(keywords))[:10]
```

5. **Lower temperature** - 0.3 for focused generation
6. **Arabic-optimized** - Native Arabic prompts for Allam

### Phase 4: Global Search (Weeks 7-8)

#### Map-Reduce with Allam

**Adaptation:** Smaller batches, focused prompts.

```python
class SLMGlobalSearch:
    """
    Global search optimized for SLMs (Allam).
    """

    def __init__(self, neo4j_client, allam_client):
        self.neo4j_client = neo4j_client
        self.allam_client = allam_client

    def global_search(
        self,
        query: str,
        community_level: int = 0,
        max_summaries: int = 20  # Reduced for SLM
    ) -> str:
        """
        Global search with SLM-optimized map-reduce.

        Key adaptations:
        1. Smaller chunks (fewer summaries per map call)
        2. Shorter prompts
        3. Conservative token limits
        """

        # 1. Get community summaries
        summaries = self._get_all_summaries(community_level)

        # 2. Limit to top N (avoid overwhelming SLM)
        summaries = summaries[:max_summaries]

        # 3. Split into smaller chunks for SLM
        chunks = self._chunk_summaries(summaries, chunk_size=3)  # 3 per chunk

        # 4. MAP PHASE: Generate partial answers
        partial_answers = []
        for chunk in chunks:
            answer = self._map_step_slm(query, chunk)
            partial_answers.append(answer)

        # 5. REDUCE PHASE: Combine answers
        final_answer = self._reduce_step_slm(query, partial_answers)

        return final_answer

    def _map_step_slm(self, query: str, summaries: List[str]) -> Dict:
        """
        Map step with Allam - smaller context window.
        """

        # Format summaries concisely
        summary_text = "\n\n".join([
            f"{i+1}. {s[:300]}..."  # Truncate to 300 chars
            for i, s in enumerate(summaries)
        ])

        prompt = f"""
        السؤال: {query}

        ملخصات المجموعات:
        {summary_text}

        أجب جزئياً بناءً على هذه الملخصات.
        قيّم مدى الفائدة (0-100).

        الصيغة:
        الإجابة: [إجابتك]
        التقييم: [رقم]
        """

        response = self.allam_client.generate(
            prompt,
            max_tokens=300,  # Short partial answer
            temperature=0.3
        )

        # Parse response
        try:
            lines = response.split('\n')
            answer_line = [l for l in lines if l.startswith('الإجابة:')][0]
            score_line = [l for l in lines if l.startswith('التقييم:')][0]

            answer = answer_line.replace('الإجابة:', '').strip()
            score = int(re.findall(r'\d+', score_line)[0])

            return {'answer': answer, 'score': score}
        except:
            return {'answer': response, 'score': 50}

    def _reduce_step_slm(self, query: str, partial_answers: List[Dict]) -> str:
        """
        Reduce step with Allam - combine top partial answers.
        """

        # Sort by score, take top 5
        sorted_answers = sorted(partial_answers, key=lambda x: x['score'], reverse=True)
        top_answers = sorted_answers[:5]

        # Format for reduce
        answers_text = "\n\n".join([
            f"{i+1}. {a['answer']}"
            for i, a in enumerate(top_answers)
        ])

        prompt = f"""
        السؤال: {query}

        إجابات جزئية من مجموعات مختلفة:
        {answers_text}

        اجمع هذه الإجابات في إجابة شاملة واحدة.
        كن موجزاً ودقيقاً (3-4 فقرات).
        """

        final_answer = self.allam_client.generate(
            prompt,
            max_tokens=600,  # Comprehensive but not too long
            temperature=0.3
        )

        return final_answer.strip()

    def _chunk_summaries(self, summaries: List[str], chunk_size: int = 3) -> List[List[str]]:
        """Split summaries into chunks for SLM processing."""
        chunks = []
        for i in range(0, len(summaries), chunk_size):
            chunks.append(summaries[i:i+chunk_size])
        return chunks

    def _get_all_summaries(self, level: int) -> List[str]:
        """Get all community summaries at level."""
        query = """
        MATCH (c:Community {level: $level})
        WHERE c.summary IS NOT NULL
        RETURN c.summary as summary
        ORDER BY c.entity_count DESC
        """

        results = self.neo4j_client.execute_query(query, {'level': level})
        return [r['summary'] for r in results]
```

**Key Adaptations:**

1. **Smaller chunks** - 3 summaries per map call (vs 10-15 for GPT-4)
2. **Truncated summaries** - 300 chars each
3. **Fewer partial answers** - Top 5 for reduce (vs 10-15)
4. **Conservative tokens** - 300 map, 600 reduce
5. **Arabic-optimized prompts**

### Phase 5: Local & Hybrid Search (Weeks 9-10)

#### Local Search - Minimal LLM Use

```python
class SLMLocalSearch:
    """
    Local search with minimal SLM dependency.
    """

    def __init__(self, neo4j_client, qdrant_client, allam_client):
        self.neo4j_client = neo4j_client
        self.qdrant_client = qdrant_client
        self.allam_client = allam_client

    def local_search(self, query: str, max_hops: int = 2) -> str:
        """
        Local search using graph traversal + vector search.
        LLM only used for final answer generation.
        """

        # 1. Extract entities from query (rule-based)
        query_entities = self._extract_entities_rules(query)

        # 2. Find matching entities in graph (no LLM)
        matched_entities = self._find_entities_in_graph(query_entities)

        # 3. Graph traversal (no LLM)
        context_entities = []
        for entity in matched_entities:
            neighbors = self._get_neighbors(entity, max_hops)
            context_entities.extend(neighbors)

        # 4. Get community context (no LLM)
        communities = self._get_entity_communities(matched_entities)
        community_summaries = [self._get_community_summary(c) for c in communities]

        # 5. Vector search for chunks (no LLM)
        chunks = self.qdrant_client.search(query, limit=10)

        # 6. Combine context
        context = {
            'entities': context_entities[:20],  # Limit for SLM
            'relationships': self._get_relationships(context_entities)[:15],
            'chunks': chunks[:5],  # Top 5 chunks
            'community_summaries': community_summaries[:2]  # Top 2 communities
        }

        # 7. Generate answer with Allam (ONLY step using LLM)
        return self._generate_answer_slm(query, context)

    def _extract_entities_rules(self, query: str) -> List[str]:
        """Extract entities using rules (no LLM)."""
        # Simple approach: Capitalize words as potential entities
        words = query.split()
        entities = []

        for word in words:
            # Heuristic: Capitalized words or Arabic proper nouns
            if word[0].isupper() or self._is_arabic_proper_noun(word):
                entities.append(word)

        return entities

    def _is_arabic_proper_noun(self, word: str) -> bool:
        """Heuristic for Arabic proper nouns."""
        # Check if word contains Arabic characters
        arabic_pattern = re.compile('[\u0600-\u06FF]+')
        return bool(arabic_pattern.search(word))

    def _generate_answer_slm(self, query: str, context: Dict) -> str:
        """Generate answer using Allam with focused context."""

        # Format context concisely for SLM
        entity_text = ", ".join([e['name'] for e in context['entities'][:10]])

        rel_text = "\n".join([
            f"{r['source']} → {r['target']}"
            for r in context['relationships'][:10]
        ])

        chunk_text = "\n\n".join([
            c['text'][:200]  # Truncate
            for c in context['chunks'][:3]
        ])

        community_text = "\n\n".join(context['community_summaries'][:2])

        prompt = f"""
        السؤال: {query}

        الكيانات ذات الصلة: {entity_text}

        العلاقات:
        {rel_text}

        النصوص:
        {chunk_text}

        سياق المجموعات:
        {community_text}
```

#### Hybrid Search - Rule-Based Merging

```python
class SLMHybridSearch:
    """
    Hybrid search with minimal LLM dependency.
    """

    def __init__(self, neo4j_client, qdrant_client, allam_client):
        self.neo4j_client = neo4j_client
        self.qdrant_client = qdrant_client
        self.allam_client = allam_client

    def hybrid_search(self, query: str) -> str:
        """
        Hybrid search using rule-based merging.
        LLM only for final answer.
        """

        # 1. Vector search (no LLM)
        vector_results = self.qdrant_client.search(query, limit=20)

        # 2. Graph search (no LLM)
        entities = self._extract_entities_rules(query)
        graph_results = self._find_related_entities(entities, max_hops=2)

        # 3. Get chunks for graph entities (no LLM)
        graph_chunks = []
        for entity in graph_results[:10]:  # Limit
            chunks = self._get_entity_chunks(entity)
            graph_chunks.extend(chunks)

        # 4. Merge results (rule-based scoring)
        merged = self._merge_results_rules(vector_results, graph_chunks)

        # 5. Get community context (no LLM)
        communities = self._get_entity_communities(entities)
        summaries = [self._get_summary(c) for c in communities[:2]]

        # 6. Generate answer with Allam (ONLY LLM step)
        return self._generate_answer_slm(query, merged, summaries)

    def _merge_results_rules(
        self,
        vector_results: List[Dict],
        graph_chunks: List[Dict]
    ) -> List[Dict]:
        """
        Merge vector and graph results using rule-based scoring.
        No LLM needed!
        """

        all_results = []

        # Add vector results with scores
        for result in vector_results:
            all_results.append({
                'chunk': result['text'],
                'vector_score': result['score'],
                'graph_score': 0.0,
                'source': 'vector'
            })

        # Add graph chunks with scores
        for chunk in graph_chunks:
            # Check if already in vector results
            existing = self._find_existing(all_results, chunk['text'])

            if existing:
                # Boost: Found in both vector and graph
                existing['graph_score'] = 1.0
                existing['source'] = 'hybrid'
            else:
                all_results.append({
                    'chunk': chunk['text'],
                    'vector_score': 0.0,
                    'graph_score': 1.0,
                    'source': 'graph'
                })

        # Hybrid scoring (rule-based)
        for result in all_results:
            result['hybrid_score'] = (
                0.6 * result['vector_score'] +
                0.4 * result['graph_score']
            )

        # Sort by hybrid score
        sorted_results = sorted(
            all_results,
            key=lambda x: x['hybrid_score'],
            reverse=True
        )

        return sorted_results[:10]  # Top 10

    def _find_existing(self, results: List[Dict], text: str) -> Dict:
        """Find if text already in results."""
        for r in results:
            if r['chunk'] == text:
                return r
        return None

    def _generate_answer_slm(
        self,
        query: str,
        merged_results: List[Dict],
        summaries: List[str]
    ) -> str:
        """Generate answer with Allam."""

        # Format context
        chunks_text = "\n\n".join([
            f"{i+1}. {r['chunk'][:200]}"
            for i, r in enumerate(merged_results[:5])
        ])

        summaries_text = "\n\n".join(summaries)

        prompt = f"""
        السؤال: {query}

        المعلومات المستخرجة:
        {chunks_text}

        السياق العام:
        {summaries_text}

        أجب على السؤال بناءً على هذه المعلومات.
        كن دقيقاً وشاملاً (2-3 فقرات).
        """

        answer = self.allam_client.generate(
            prompt,
            max_tokens=500,
            temperature=0.3
        )

        return answer.strip()
```

```python
import spacy

class ArabicEntityExtractor:
    """
    Entity extraction using NLP libraries + Allam validation.
    Reduces LLM dependency by 80%.
    """

    def __init__(self, allam_client):
        self.allam_client = allam_client
        # Load Arabic NLP model
        try:
            self.nlp = spacy.load("xx_ent_wiki_sm")  # Multilingual
        except:
            self.nlp = None

    def extract_entities(self, text: str) -> Dict:
        """
        Extract entities using NLP first, Allam for validation.
        """

        # Step 1: NLP-based extraction (no LLM)
        nlp_entities = self._extract_with_nlp(text)

        # Step 2: Rule-based extraction for Arabic (no LLM)
        rule_entities = self._extract_arabic_rules(text)

        # Step 3: Merge
        all_entities = self._merge_entities(nlp_entities, rule_entities)

        # Step 4: Allam validation (only for ambiguous cases)
        validated_entities = self._validate_with_allam(text, all_entities)

        # Step 5: Extract relationships (co-occurrence)
        relationships = self._extract_relationships_cooccurrence(
            text,
            validated_entities
        )

        return {
            'entities': validated_entities,
            'relationships': relationships
        }

    def _extract_with_nlp(self, text: str) -> List[Dict]:
        """Extract using spaCy (fast, no LLM)."""
        if not self.nlp:
            return []

        doc = self.nlp(text)
        entities = []

        for ent in doc.ents:
            entities.append({
                'name': ent.text,
                'type': ent.label_,
                'confidence': 0.7  # NLP confidence
            })

        return entities

    def _extract_arabic_rules(self, text: str) -> List[Dict]:
        """Extract Arabic entities using patterns."""
        entities = []

        # Pattern 1: Capitalized Arabic words (names)
        arabic_caps = re.findall(r'\b[A-Z][a-z]+\b', text)
        for name in arabic_caps:
            entities.append({
                'name': name,
                'type': 'Person',
                'confidence': 0.5
            })

        # Pattern 2: Location markers
        location_patterns = [
            r'(في|من|إلى)\s+([^\s]+(?:\s+[^\s]+)?)',
        ]
        for pattern in location_patterns:
            matches = re.findall(pattern, text)
            for match in matches:
                if len(match) > 1:
                    entities.append({
                        'name': match[1],
                        'type': 'Location',
                        'confidence': 0.6
                    })

        return entities

    def _merge_entities(self, nlp_entities: List, rule_entities: List) -> List[Dict]:
        """Merge entities from different sources."""
        # Deduplicate and combine
        seen = set()
        merged = []

        for entity in nlp_entities + rule_entities:
            if entity['name'] not in seen:
                seen.add(entity['name'])
                merged.append(entity)

        return merged

    def _validate_with_allam(self, text: str, entities: List[Dict]) -> List[Dict]:
        """
        Validate entities with Allam (used sparingly).
        Only for low-confidence entities.
        """

        # Filter: Only validate low confidence
        low_confidence = [e for e in entities if e['confidence'] < 0.6]

        if not low_confidence or len(low_confidence) > 20:
            return entities  # Skip if too many or none

        # Validate with Allam
        entity_names = [e['name'] for e in low_confidence]

        prompt = f"""

        {', '.join(entity_names)}

        النص: {text[:500]}

        لكل كيان، أجب: نعم (كيان صحيح) أو لا

        الصيغة:
        كيان1: نعم/لا
        كيان2: نعم/لا
        """

        response = self.allam_client.generate(prompt, max_tokens=200)

        # Parse validation
        validated = []
        for entity in entities:
            if entity['confidence'] >= 0.6:
                validated.append(entity)  # High confidence: keep
            else:
                # Check Allam response
                if entity['name'] in response and 'نعم' in response:
                    entity['confidence'] = 0.8
                    validated.append(entity)

        return validated

    def _extract_relationships_cooccurrence(
        self,
        text: str,
        entities: List[Dict]
    ) -> List[Dict]:
        """
        Extract relationships based on co-occurrence (no LLM).
        FastGraphRAG approach.

        relationships = []

        # Split text into sentences
        sentences = re.split(r'[.!?]+', text)

        # Find entity pairs in same sentence
        for sentence in sentences:
            # Find which entities appear in this sentence
            entities_in_sentence = []
            for entity in entities:
                if entity['name'] in sentence:
                    entities_in_sentence.append(entity)

            # Create relationships for co-occurring entities
            for i, e1 in enumerate(entities_in_sentence):
                for e2 in entities_in_sentence[i+1:]:
                    relationships.append({
                        'source': e1['name'],
                        'target': e2['name'],
                        'type': 'CO_OCCURS',
                        'confidence': 0.7
                    })

        return relationships
```
